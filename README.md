# 下一餐

一个适合在手机和微信中打开的纯前端餐厅选择网页。好友对每家餐厅选择“打叉 / 待定 / 打钩”后会自动进入下一家，全部完成后生成一张结果图片。

## 修改餐厅

推荐打开 `editor.html` 使用表格修改。表格会自动保存草稿，并支持应用到预览、直接写回 `restaurants.js` 或下载新的 JS 文件。也可以直接打开 `restaurants.js`，修改 `RESTAURANTS` 数组。

- `name`：餐厅名称
- `category`：菜系或餐厅类型
- `location`：区域和地址
- `price`：人均价格
- `time`：适合的用餐时间
- `description`：餐厅简介
- `tags`：推荐菜或特点
- `image`：封面图片路径或完整图片网址
- `emoji`、`colors`：没有封面图片时显示的占位图案和渐变颜色
- `recommendedDishes`：推荐菜，最多显示四项；每项可填写名称、图片和备用 emoji
- `dianpingUrl`：大众点评餐厅页面的完整链接，以 `https://` 开头
- `scores`：距离、美味、新奇和 E宝四项星级，填写 1–5 的整数

建议把自己的图片放入项目中的 `images` 文件夹，再把 `image` 写成 `images/图片名.jpg`。

项目已经建立统一图片目录和命名规则。封面放在 `images/covers`，菜品图片放在 `images/dishes`。完整对照请查看 `图片路径说明.md`。打包或上传时需要保留整个 `images` 文件夹。

## 使用

直接打开 `index.html` 可以本地预览。要分享给微信好友，需要把整个文件夹部署到一个支持 HTTPS 的静态网站空间，然后分享生成的网址。

选择进度只保存在好友自己的浏览器中，不会上传到服务器。完成后：

1. 支持系统图片分享的浏览器会调出分享面板；
2. 微信中如果不能直接分享文件，可长按生成的结果图保存，再发送给你；
3. “保存到手机”在部分浏览器会直接下载图片。

第一轮只有一家“想去”时会自动将其设为最终选择；存在多家“想去”时，会从所有“想去”和“待定”餐厅中再确认一家。最终餐厅会显示在生成的结果图上。

## 文件说明

- `index.html`：页面结构
- `styles.css`：页面样式和手机适配
- `restaurants.js`：餐厅数据，日后主要编辑这个文件
- `script.js`：选择流程、本地保存和结果图生成
- `editor.html`：可编辑并写回 JS 的餐厅信息表
- `editor.css`、`editor.js`：表格编辑器的样式与功能
